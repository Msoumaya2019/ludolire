# rang: 30
# Monsieur le chat

Monsieur le chat a un œil brun.
La femme de monsieur le chat a une valise.
Dans la valise, il y a un poisson.
Le second chat est dans la maison.
Le fils de la reine aime le poisson.
Monsieur le chat appelle la reine.
La reine arrive avec une pomme.
Le chat aime la pomme rouge.
Le fils a une question.
Monsieur le chat a une réponse.
La femme rit encore.
