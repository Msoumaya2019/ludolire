# rang: 38
# La pomme d'or

La reine a un chat brun.
Le chat aime les pommes.
Un matin, il arrive dans le jardin.
Dans le jardin, il y a un pommier.
Sur le pommier, une pomme d'or.
Le chat monte sur une échelle.
Il appelle la reine.
Elle arrive avec une valise.
Elle a une question.
Le chat a une réponse.
Ils mangent la pomme ensemble.
Le soir, ils dorment dans la maison.
La reine aime son chat brun.
